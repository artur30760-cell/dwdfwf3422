# Telegram Бот для продажи промтов (Telegram Stars)

Бот для автоматической продажи цифровых промтов и инструкций с оплатой через **Telegram Stars (Звёзды)**.

---

## 📁 Структура проекта

* `bot.py` — основной код бота и обработчики (каталог, создание счетов, подтверждение, выдача товара, уведомление админа).
* `config.py` — настройки бота, токен, ID владельца, ссылки на отзывы/поддержку, а также **каталог товаров (цены, тексты промтов, инструкции)**.
* `keyboards.py` — интерактивные кнопки меню и каталога.
* `requirements.txt` — зависимости проекта.

---

## 🚀 Как запустить бота

1. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Запустите бота:**
   ```bash
   python bot.py
   ```

---

## ⚙️ Как настроить цены и тексты промтов

Откройте файл `config.py`:
1. В словаре `PRODUCTS` для каждого товара укажите:
   * `"price"` — цену в звёздах (например: `15`, `50`, `100`).
   * `"prompt_text"` — ваш текст промта.
   * `"instruction"` — пошаговую инструкцию.
   * `"description"` — краткое описание товара перед покупкой.
